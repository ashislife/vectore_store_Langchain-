# LangChain Vector Store (ChromaDB)

This repository demonstrates how to use **ChromaDB** as a vector store in LangChain for storing, indexing, and retrieving document embeddings.

## Project Structure

```text
vector_store_langchain/
├── langchain_chroma.ipynb
├── README.md
├── LICENSE
└── .gitignore
```

## Features

- ChromaDB Integration
- Vector Store Creation
- Document Embedding
- Similarity Search
- Document Retrieval
- LangChain + ChromaDB Workflow

## Prerequisites

- Python 3.10+
- LangChain
- langchain-community
- chromadb
- python-dotenv

## Installation

Clone the repository:

```bash
git clone https://github.com/ashislife/vector_store_Langchain-.git
```

Navigate to the project directory:

```bash
cd vector_store_Langchain-
```

Install the required dependencies:

```bash
pip install langchain langchain-community chromadb python-dotenv jupyter
```

## Usage

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open and run:

```text
langchain_chroma.ipynb
```

Execute the notebook cells sequentially.
